# Empyrium Mod


## Features

3 Factions :
- Each faction has a capital defined by admins
- Mayors can create sell-able and buyable plots
- Allow mayors to add taxes
- Community System (Factions inside factions, more like communities inside a species category)
- Each factions have powers / downsides
- (Future) addons to add more factions

Economy :
- Multi-currency system (item-icon, name, etc)
- Admin Shop + Player Shop

Difficulty System (death)
- Safe: Keep Inventory/ Keep Exp for the player
- Normal: Vanilla behavior for the player

## What have been done
- Difficulty System: 100%
- Factions & Powers: 85% (no capitals/no config)
- Economy: 70% (1 Currency created: Players can see their balance in the HUD. Also commands for admins to give/take/set balance)
- Player Shop: 100% (maybe bug fixes to do)
